AI 辅助识别（可选）

规则认不出的字段、对不上的下拉选项，交给大模型善后。用你自己的 API Key（OpenRouter 或任何 OpenAI 兼容接口），费用很低：一次填写通常只有 1~2 次调用。

  • 认标签时只发送网页上的字段标签和你资料里有值的字段名称，不发送任何资料内容。
  • 挑下拉选项时，会发送该字段的资料值和网页选项（如「专业类别」「信息来源」）；姓名、证件号、手机、邮箱、地址、生日、紧急联系人、学号等敏感字段永远不发。
  • API Key 只存在本机，由插件后台直接调用接口；网页和内容脚本都拿不到。导出 JSON 不包含 Key。
  • AI 只在规则失败时才调用；它给的选项必须是网页上真实存在的，编造的一律不用。
